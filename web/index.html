Hyperliquid 现货与合约标的来源性质分类速查

Hyperliquid 拥有独特的 L1 混合代币架构（官方原生、社区 HIP-1、Unit 映射与跨链桥）。不同性质的标的在流动性、预言机安全性及质押属性上存在重大差异：

🏛️ 官方 Canonical 原生 最高安全级 / 支持质押

典型代表: PURR, USDC, HYPE

底层机制: Hyperliquid 官方创世部署或核心原生代币 (isCanonical=true)。官方验证节点统一定价预言机，流动性充裕，无虚假碰撞风险。

套利实操: 在 Portfolio Margin 账户中享有 50% 官方质押折算率，是运行【方案 D】现货质押对冲的标准核心标的。

🌉 Unit Protocol 封装映射 主流封装 / 现货对冲

典型代表: UBTC, UETH, USOL, UZEC, UENA, UFART, UPUMP, UBONK

底层机制: Unit Protocol 协议在 Hyperliquid L1 发行的跨链资产封装代币（统一以 U- 为前缀）。

套利实操: 解决 L1 原生现货匮乏问题，适合 1:1 现货全款持有对冲。目前在账户中作为独立现货持仓（非跨资产质押品），需关注 Unit 铸造/赎回流动性。

🌉 HyBridge 跨链桥接 跨链映射 / 关注基差

典型代表: LINK0, AAVE0, XMR1, BNB1, CFX0

底层机制: 通过 HyBridge / Wagyu 桥接至 Hyperliquid L1 的资产，名称后通常带有数字后缀（如 0 或 1）。

套利实操: 需关注跨链桥深度与跨链桥安全；开仓前必须核对现货与永续之间的基差（Basis Spread），防止滑点摩擦。

⚡ HIP-1 社区无许可发币 社区创建 / 防撞车

典型代表: AZTEC, @260, @107, HFUN

底层机制: 社区通过 Hyperliquid L1 HIP-1 荷兰拍/联合曲线标准无许可发行的代币 (isCanonical=false)，底层交易对为 @<index>。

套利风控: ⚠️ 极度警惕同名模因币碰撞！开仓前务必核对底层真实 Pair ID；需关注部署者手续费分成 (deployerFeeShare) 与潜在抛压。

核心量化指标与算式解析

1. 资金费率与年化利率 (Funding Rate & APR)
  • 1小时资金费率 ($r_{1h}$): Hyperliquid 采用 1 小时逐笔结算机制；Bybit 默认采用 8 小时结算机制 ($r_{1h} = r_{8h} / 8$)。
  • 单利年化利率 (Simple APR):
    $$\text{APR} = r_{1h} \times 24 \times 365 \times 100\%$$
  • 复利年化收益 (Compound APY):
    $$\text{APY} = \left((1 + r_{1h})^{8760} - 1\right) \times 100\%$$
2. 市价单手续费回本时间 (Payback Hours)
  • 单边开仓回本时长 (Entry Payback):
    $$T_{\text{entry}} = \frac{\text{Fee}_{\text{Spot}} + \text{Fee}_{\text{Perp}}}{r_{1h}} \quad (\text{小时})$$
  • 双边完整回本时长 (Roundtrip Payback):
    $$T_{\text{roundtrip}} = \frac{2 \times (\text{Fee}_{\text{Spot}} + \text{Fee}_{\text{Perp}})}{r_{1h}} \quad (\text{小时})$$
  • 风控卡口准则: 优先选择完整回本时间 $\le 48\text{h}$ 的高资费标的，严禁入场回本时间 $> 72\text{h}$ 或负资费标的。
3. 基差偏离度 (Basis Spread)
  • 基差公式:
    $$\text{Spread} = \frac{P_{\text{Perp}} - (P_{\text{Spot}} \times \text{Multiplier})}{P_{\text{Spot}} \times \text{Multiplier}} \times 100\%$$
  • 正基差 ($>0$): 永续价格高于现货价格。开仓（买现货+空永续）获得溢价保护，平仓时基差收敛带来额外利润。
  • 负基差 ($<0$): 严禁大幅负基差入场，否则平仓时基差收敛将侵蚀资金费率收益。

Hyperliquid 现货质押与合约对冲套利（方案 D）核心法则

⚡ 方案 D (Scheme D) 黄金资金配比: 90% 现货质押 + 90% 永续做空 + 10% USDC 现金缓冲
1. 组合保证金 (Portfolio Margin) 账户准入

必须在 Hyperliquid 开通 Portfolio Margin 模式。门槛：账户资产 $\ge \$10,000$ 或历史累计交易量 $\ge \$5,000,000$。

2. 50% 折价质押与强平线推导

现货 Token 按 50% 抵押率提供保证金。即使现货极端暴涨，空头亏损的同时现货质押价值也同步增长，系统经受得起 $+109.6\%$ 的翻倍暴涨而绝不爆仓。

3. 三级阶梯动态调仓风控准则
  • Level 1 (注入缓冲): 保证金使用率 $>60\%$ 或强平距离 $<25\%$ $\to$ 将 10% 闲置 USDC 划转至永续子账户（0 手续费）。
  • Level 2 (等比例减仓): 保证金使用率 $>75\%$ 或强平距离 $<15\%$ $\to$ 同步市价平掉 $25\%\sim 30\%$ 现货与永续仓位。
  • Level 3 (紧急熔断): 强平距离 $<8\%$ $\to$ 立即强平 $\ge 50\%$ 仓位锁定本金。
